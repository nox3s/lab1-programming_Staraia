# Лабораторная работа № 2. Знакомство со средой разработки. Git. Базовый синтаксис C++ и Python.
## Описание
В репозитории представлены два файла с примерами базового синтаксиса языков программирования C++ и Python. Программы демонстрируют работу с выводом данных, переменными, функциями и типизацией.

## Файлы проекта
*   **Untitled-1.cpp** — пример на языке C++. Демонстрирует вывод данных, работу со строками, униформ-инициализацию (`auto number{7}`) и функцию с трейлинг-возвращаемым типом (`auto square(int x) -> int`).
*   **hello.py** — пример на языке Python. Демонстрирует вывод данных, динамическую типизацию, f-строки и функцию с аннотациями типов (`def square(x: int) -> int`).

## Функционал программ
Обе программы выполняют следующие действия:
1. Выводят приветствие «Hello, World!».
2. Выводят имя студента и текущую дату.
3. Вычисляют и выводят квадрат заданного числа (число 7).

## Как запустить

### Для C++ (Untitled-1.cpp)
1. Убедитесь, что у вас установлен компилятор `g++` (например, через MSYS2).
2. Откройте терминал в папке с файлом.
3. Выполните команду для компиляции:
   ```bash
   g++ -std=c++17 -Wall -o app Untitled-1.cpp
4. Запустите программу:
    В Windows (cmd): app.exe
    В PowerShell: .\app.exe

## Для Python (hello.py)
1. Убедитесь, что у вас установлен Python 3.x.
2. Откройте терминал в папке с файлом.
3. Выполните команду:
    python main.py
